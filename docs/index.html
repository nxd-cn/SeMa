SeMa

一个窗口，管理多个 AI CLI 会话

跨平台桌面应用（Windows / macOS）。按项目目录打开 Claude Code、Cursor Agent、Codex、Gemini 等，支持分栏、续聊与未读提示。

查看源码 下载最新版

支持的 CLI

已安装并配置 PATH 的工具会出现在列表中；Terminal 始终可用。

Claude Code Cursor Agent OpenCode Codex Gemini Pi Kimi Code Terminal

能做什么

为多项目、多助手并行工作流设计。

按目录开会话
选择项目路径与 CLI，每个会话绑定工作目录。
分栏与合并
同组多分栏并排工作；拖拽 tab 可排序或合并。
续聊与未读
有历史时可续聊；非当前组有回复时侧栏蓝点 + Toast。
Git 分支底栏
只读显示当前分支；未安装 git 时显示 ~。

技术栈

桌面壳 + 终端渲染 + 本地 PTY。

Tauri 2 Rust React / TypeScript xterm.js portable-pty
